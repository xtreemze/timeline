    Node-edge model
    
              
    Build the relation graph
    
            
    
          
    

          
    
            
            
    Node
    noun / subject
    
            
            
            
    One node = one durable entity. A canonical node must participate in at least one meaningful action edge; stories, categories, navigation containers, roles, events, actions, time, and places stay outside graph topology. A node must not contain a verb, date/time, place/location, coordinates, radius, or geometry. Put the action in the edge predicate, time in edge.time, and spatial context in edge.placeId.
    
            
    
              Identity & provenance optional
              
              
              
              
    Use source IDs to link this reusable entity to evidence or provenance records without copying source details into the node.
    
            
    
            
            
    
            
    
              
              
            
    
          
    

          
    

          
    
            
            
    Place
    reusable spatial record
    
            
    Create a place once, then reference it from any number of edges. Places are map records, never graph nodes and never part of an edge label.
    
            
            
            
            
            
            
            
            
            
            
    
            
    
              
              
            
    
          
    

          
    

          
    
            
            
    Edge
    action / relation
    
            
            
            
            
            
            
            
            
    
              Provenance & confidence optional
              
              
              
    Confidence describes support for this relationship, not either endpoint. Source IDs link the assertion to evidence or provenance records.
    
            
    
            

            
    
              Active time recommended
              
              
    Time/date/period is a property of the edge and drives timeline projection. It must not be embedded in the action label. Use persistent only when the action genuinely has no temporal extent.
